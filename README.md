# Voxis Mic Control

<img width="646" height="437" alt="image" src="https://github.com/user-attachments/assets/266636d4-8e37-4830-b80c-c74872c4813c" />


A lightweight Windows microphone control utility - mute/unmute hotkeys, volume control, auto-mute on idle, and a per-app capture tracker, all from a small always-available window and system tray icon. RAM stays at around 7.5mb

## Features

- Global mute/unmute hotkey (toggle or push-to-talk)
- Global hotkey to bring the app to front from anywhere
- Volume control
- Auto-mute after a period of inactivity
- On-screen popup indicator when mute state changes
- See which apps are currently capturing your mic

## Install

Download the latest installer from the [Releases](https://github.com/Squibble34/Voxis-Mic-Control/releases) page and run it.

> **Note:** Since this is a small, unsigned, independently-built app, Windows Defender or SmartScreen may flag it on first run. This is a false positive, not a sign of anything actually malicious, it is just because it is not code signed (which costs a lot). the source is fully open in this repo if you want to verify.
